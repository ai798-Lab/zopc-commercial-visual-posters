# 使用帮助

[返回首页](../README.md) · [安装步骤](INSTALL.md)

## 安装后没有出现

确认安装目录打开后直接包含SKILL.md、assets、references、scripts和agents；不要多套一层仓库目录。完整下载后新开对话，必要时重启Codex。不要同时在多个位置安装同名Skill。

## 可以看图，但没有生成海报

目录脚本只负责读取素材或准备任务。实际出图需要当前环境可用的图片生成/编辑能力，账号是否具备能力和额度由客户端决定。

## 角色或样式不符合选择

保留本次填写的信息，并提供形象ID、样式ID、期望与实际差异。选用自定义原图时确认附件实际收到；不要把缺原图自动替换成文字创作。

## 价格、日期或二维码不正确

当前样张没有固定活动价格、日期或赠券。请确认本次提供的数据；二维码使用当前原图，成品需要解码核对。无二维码版本应删除扫码文案和占位框，并重新排版。

## 如何报告问题

[打开问题模板](https://github.com/ai798-Lab/zopc-commercial-visual-posters/issues/new/choose)。可附已脱敏的截图与复现步骤；不要上传密钥、客户资料、私人聊天或未获授权的形象原图。

本仓库目前未启用GitHub私密漏洞报告。涉及敏感信息时，不要使用公开Issue；请使用你与ai798 Lab已有的私下联系渠道。

## English

Check that the installed folder directly contains SKILL.md and all resources. Start a new conversation or restart Codex if necessary. Image generation depends on your client's available capability; the Python helpers do not generate artwork.

For problems, include the client, mascot/style IDs, expected result and redacted reproduction material. Never post credentials, private conversations or customer data in a public issue. Private vulnerability reporting is not currently enabled.
