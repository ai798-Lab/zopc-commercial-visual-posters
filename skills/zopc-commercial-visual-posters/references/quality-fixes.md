# 历史问题与当前样张修整

当前公开包包含重新整理的S01–S11实际示例，不包含历史原稿。以下记录说明修整来由；生产时采用当前S样张，不继承旧活动信息。

- V1六方向的“20天”和双券：原稿由维护方另行保留，不进入本公开包。按用户最新要求，当前11张样张已删除整块赠送21天实战营×2的券、条带与装饰。新活动只有用户明确提供赠送权益时才加入，天数和数量均不预设。
- 早期小人/动物不统一：当前十一张样张采用十个母版各一次，加C01自定义小象，保持统一潮玩家族；物种与配色仍不同。
- 柴犬像狐狸：母版保留宽圆脸、短口鼻、奶油色口鼻与胸前、较小立耳、卷尾；橙色为用户最终选择。其它动物各有特征。
- 卡面瑕疵：删除无意义划痕、乱码、小字和多余穿字线；标题/年度会员/权益条在其透视平面居中。
- 卡片下边距太窄：权益条与下缘及其它信息保持清楚间隔，不让文字接缝。
- Logo位置不一致/挤边：当前示例统一使用真实Logo图层和一套边距，明亮背景使用小型深色底板承载白色字标。
- 旧长说明过密：演示不再携带“按季购买全年（399×4）”及活动价格；真实价格根据新填写单排版。
- QR被模型画坏或文件MIME不符：当前S示例不含QR；正式扫码版使用当前用户原码独立嵌入、检查真实格式并解码。
- 旧直播日期、折扣被错误沿用：样张去除历史时间与售价，本公开包不含历史图。示例的文案也不能当新活动已确认权益。
- 无二维码版出现空白洞：重排底部为完整文字区，不保留占位框、扫码句和箭头。
- 兔子母版耳朵裁切：已重新生成更宽松的完整构图，正式母版保留两只完整长耳和足部。

样式保留各自字体与气氛：S01衬线金字，S02黑粗字，S03暖金字，S04巨型AI字雕与促销大字，S05银色字，S06蓝橙粗字，S07蓝青立体字，S08毛笔+窄字，S09紫色发光艺术字，S10白色大字+手写，S11白色刷字+舞台。S04原先巨型2属于赠送数量，已一并改为AI字雕，名称为“巨型字雕”。统一制作质量，不强制全部改为同一配色。
