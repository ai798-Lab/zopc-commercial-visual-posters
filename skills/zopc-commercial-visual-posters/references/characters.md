# 形象选择与统一风格

预设严格为十个：M01橙柴、M02熊猫、M03机器人、M04柯基、M05奶牛猫、M06兔子、M07棕熊、M08企鹅、M09水獭、M10小恐龙。母版在 assets/mascots/，具体特征见 catalog.json。角色母版是参考，不是直接贴到任何背景的成品。

统一语言是圆润大头、小体形、细腻三维材质、紫色透明眼镜/面罩、炭黑与橙色服装细节。毛绒动物、机器人陶瓷金属、小恐龙软胶分别呈现真实材料差异。保持物种轮廓：熊猫圆耳黑眼斑，兔子完整长耳，企鹅鳍肢蹼足，机器人真实关节；不靠给柴犬换颜色冒充其它物种。

自定义有两种入口：上传形象图；文字描述物种/主体、颜色、识别特征和必须保留的配饰。用户只说“用我的形象”且尚无图片/描述时，就索取该信息，不擅选柴犬。文字自定义可先制作一张小型角色母版；需要锁定身份时请用户选择或修正后用于海报。自定义用户若已给清晰母版和全部信息则直接制作。

统一风格不等于改掉自定义形象的颜色、物种或轮廓。保留明确识别点，把材质、比例、光线与海报家族对齐；服装、眼镜等配饰按用户要求调整。不要自动把 ZOPC 字样、项链或其它品牌符号加到别人的角色身上。

C01 原创小象是自定义路径示范，只用于 S05 展示。图库中十一张样式使用十个预设各一次加此自定义示范；这种搭配不是绑定关系。任何预设或自定义角色都可与任意样式配对。

内部制作信息中，用户明确说使用上传原图就记录 custom.mode="uploaded"；在收到真实图片前不改走文字重画。用户明确选择用描述创造新形象时记录 custom.mode="description"。文字描述可补充上传图的识别点，但不替代用户要求使用的原图。面向用户仍用自然语言沟通，不让用户填写JSON。
