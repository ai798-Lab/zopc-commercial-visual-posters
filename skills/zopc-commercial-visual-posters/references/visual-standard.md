# 运营视觉十维审稿

摘自ZOPC既有运营视觉规范，保留可直接执行的判断。用户本次明确要求优先。

| 维度 | 设计与检查 |
| --- | --- |
| 目标与受众 | 第一眼应看到本次最重要的信息，行动引导与真实目的相符。 |
| 概念与情绪 | 角色动作、道具和空间表达同一个主题，能说明它们为何出现。 |
| 信息层级 | 标题、主要利益、操作与说明有明确级差；金额日期不能被装饰盖住。 |
| 构图与焦点 | 明确主体尺度、视角、裁切与重心；不同画幅独立排版，关键识别点安全。 |
| 字体与排版 | 标题可有鲜明字效，长说明清楚稳定；检查中文、英文、数字及换行。 |
| 色彩与对比 | 有主色关系，强对比用于重点；发光、浅字、渐变在手机尺寸下能读。 |
| 图像与材质 | 毛绒、软胶、金属、玻璃有区别；光源、反射、接触阴影和透视一致。 |
| 空间与疏密 | 主体与背景分离，文字周边低干扰；图文、内部与章节间距清楚。 |
| 模块节奏 | 长页逐段有重点、自然衔接；检查完整长页，不能以首屏通过代替全页。 |
| 延展与落地 | 系列统一字效角色、配色、Logo和组件；实际尺寸、裁切压缩及导出逐项核实。 |

交付检查：文案逐字核对；角色完整且物种可辨；卡片内容居中；单条权益和乘数准确；Logo安全边距；无二维码版重新布局；有二维码版以当前用户原码解码对照；旧版本保留；最终文件与源稿正常打开。未进行的平台上传、审核、外部页面、运营效果验证如实说明。

本套统一潮玩家族，S01–S11仍保留不同构图和配色。三维、固定比例或满版不能升级成所有设计的通用要求。
