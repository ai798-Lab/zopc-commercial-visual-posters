# 用户选择延展后再使用

确认要延展哪些物料，可选详情长页、权益图、商品图、直播预告、倒计时、横版封面、方形社媒图。用户已给范围时直接按范围做。

固定已选角色身份、主标题的字体角色、配色关系、材质与Logo基准。根据新内容选择不同动作、镜头和道具，不重复每张同一头部特写。不同尺寸独立排版，保留原比例母稿；不能靠硬裁解决横竖变化。

详情页按决策顺序分段：是什么、适合谁、实际权益、内容/交付方式、规则、行动入口；所有事实以当前材料为准。海报无法承载的正文进入后续模块，避免塞入首屏。

直播预告清楚给出时间和讨论主题，预约入口确实存在才引导预约。无二维码的社区发布图可选一个与内容有关的问题收尾，站外直播不能冒充站内入口。

倒计时使用真实目标时间和用户时区，过期历史时间先核对用途。系列同时交付时并排查看Logo、色彩和字效是否一致，检查各尺寸完整内容及导出包。
